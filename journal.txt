### Understanding C and Compilation

- `main()` function in C is special because it is the starting point when i run any program. when i return from `main()`, the program exits and passes the returned integer back to the OS, ie `0` (`return 0`). a return value of 0 indicates success.
- C is a compiled language, so we need to run our program through a C compiler to turn it into an executable file. we then run that executable like we run any other program on the command line.
- to compile our `kilo.c` file, we run:

```bash
cc kilo.c -o kilo
